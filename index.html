Configuration 🔧
Suis ces étapes une fois pour connecter Firebase et tout fonctionnera pour tous tes amis.
1
Crée un projet Firebase

Va sur console.firebase.google.com, crée un projet, active Firestore Database en mode test, et Storage.

2
Récupère la config Firebase

Dans ton projet → ⚙ Paramètres → Ajouter une application Web → copie l'objet firebaseConfig.

3
Colle ta config ici
4
Règles Firestore (mode test)

Dans Firestore → Règles, colle :

rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /{doc=**} {
      allow read, write: if true;
    }
  }
}
5
Clé API Gemini (Gratuit 🎉)

Va sur aistudio.google.com → "Get API key" → "Create API key" → copie-la ici.

✅ 100% gratuit — stockée localement dans ton navigateur.

6
Déploie sur GitHub Pages

Crée un repo GitHub public, upload index.html, active GitHub Pages (Settings → Pages → main branch). Partage le lien à tes amis !
