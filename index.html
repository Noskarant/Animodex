1
Config Firebase
Sur console.firebase.google.com → ton projet → ⚙ → "Ajouter app Web" → copie le firebaseConfig JSON ici.
2
Règles Firestore
Dans Firestore → Règles, colle et publie :
rules_version = '2';
service cloud.firestore {
  match /databases/{db}/documents {
    match /{d=**} {
      allow read, write: if true;
    }
  }
}
3
Clé Gemini (gratuit 🎉)
Sur aistudio.google.com → "Get API key" → "Create API key" → colle-la ici.
4
Déployer sur GitHub Pages
Crée un repo GitHub public → upload index.html → Settings → Pages → branch main → Partage le lien à tes amis !
